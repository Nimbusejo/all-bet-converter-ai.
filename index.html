How real conversion should work

  1. Decode the source code through a legitimate supported integration.
  2. Resolve each event to a unique fixture and kickoff time.
  3. Map each selection to the equivalent destination market.
  4. Flag unavailable, suspended or non-equivalent markets—never silently substitute.
  5. Build the destination slip using an approved API or share-code feature, then verify the returned code.
